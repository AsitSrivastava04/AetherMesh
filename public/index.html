📦 Understanding Partition Testing & Multi-Hop DTN

The Disaster Scenario: When cell towers and internet fall silent, networks fracture into isolated islands (partitions). Aether Mesh uses Delay-Tolerant Networking (DTN) so each phone or laptop acts as a Data Mule—storing messages locally in IndexedDB and automatically carrying & offloading them when peers re-enter range.
1

Simulate an Isolated Island (Partition ON)

Flip the PARTITION TEST toggle ON on your device. Direct WebRTC transmissions are paused, simulating stepping outside wireless range.

2

Send Disaster Dispatches (Store in IndexedDB)

Type a message and click SEND. Notice the badge says ⏳ DTN Buffered. Messages are safely preserved in browser IndexedDB even if the page refreshes!

3

Rejoin the Mesh (Instant Auto-Flush)

Flip PARTITION TEST back OFF. The DTN engine immediately offloads all stored bundles over WebRTC channels to neighboring peers in <50ms!

4

Multi-Hop Forwarding (Node A ↔ Node B ↔ Node C)

If Node C is not in direct range of Node A, select Node C in the recipient dropdown (or type its ID). Node A forwards the packet to Node B, and Node B relays it directly to Node C with a [2 hops] verification badge!
